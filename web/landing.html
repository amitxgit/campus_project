Attendance

Stop the usual ways students fake attendance.

Students usually fake attendance in two ways. Someone in class forwards the code to a friend at home, or one student marks friends from their own phone. Batchwise blocks both.

Proves the phone is in the room

Bluetooth check-in

The teacher's phone broadcasts a code that changes every few seconds. Students' phones have to be nearby to pick it up, so there's nothing to forward.

Proves the student is there

Fingerprint and face machines

Already have a ZKTeco or eSSL machine? Connect it, and each punch marks the student present in the class running at that time.

Backup when Bluetooth is off

Rotating QR code

A code on the teacher's phone that changes every 5 seconds and is checked on the server. Teachers can switch it off for Bluetooth-only classes.

One phone, one student

Each student checks in from their own phone only, and a phone can mark one student per class. Signing in to a friend's account to mark them doesn't work.

Your data and your costs

Your institute's data is kept separate.

Every institute gets its own database, set up in Google Cloud's Mumbai region. There are no ads.

Parent messages cost nothing if staff send them from their own WhatsApp, which takes one tap. To send them automatically from the institute's number, connect WhatsApp Business. Meta then charges a few paise per message.
